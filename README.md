# L’Atout

Application de Corentin Laurent, créée avec Claude.

Site public : https://latout-corentin-laurent.coco199504.chatgpt.site

Le fichier `index.html` est autonome : polices, styles et scripts sont intégrés. Il fonctionne sans compte, sans serveur applicatif et sans clé API. La progression éventuelle est enregistrée dans le navigateur du joueur.

Ouvrir `index.html` dans un navigateur pour jouer localement. Cette branche contient l’application destinée à la publication.
